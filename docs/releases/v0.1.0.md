# IRMDS v0.1.0 - Stabilized Multi-Domain Runtime

Released: 2026-05-04

IRMDS v0.1.0 is the first stabilized v0 release of the project.

It proves the core architectural bet: a small runtime can coordinate multiple
very different anomaly detection domains through one module lifecycle, one
event bus, one metrics path, one API, and one dashboard foundation.

## Highlights

- Stabilized sync/threaded kernel contract.
- Integrated four module domains:
  - visual
  - network
  - finance/timeseries
  - infrastructure
- Added dry-run command infrastructure with simulated actuation only.
- Added FastAPI command routes.
- Added deterministic sample data.
- Cleaned README, roadmap, and project positioning.
- Verified locally with compile, lint, type-check, and tests.

## Verification

```bash
python -m compileall -q api core modules dashboard cli notifications tests scripts
ruff check .
mypy core api modules
pytest tests -q
git diff --check
```

## Safety Boundary

This release does not perform real hardware actuation. The command system is
dry-run/simulated only.

## Known Limitations

- Visual inference depends on local camera/video/model availability.
- Dashboard coverage is still early and does not yet expose full pages for all
  four modules.
- CI and Docker are added after the v0.1.0 tag and belong to the next release
  line.
- No real actuation, policy engine, RBAC, command signing, or certified safety
  integration exists in this release.
